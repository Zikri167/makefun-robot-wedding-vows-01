One-line robot wedding vows: a program that writes the funniest single line of wedding vows a robot couple could say. A classic vow cadence with machine substitutions — sickness and health, airplane mode and roaming — and the twist lands in the last words: a marriage that lasts only till the warranties expire.

## Run it

```sh
node main.ts
```

It writes one line (122 characters, no newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validated in-program to be 1–160 characters and a single line.
